# Tata Caseirinhos — site de bolos caseiros

Abra `index.html` no navegador para ver o site.

## Estrutura
- `index.html` — página (textos e seções)
- `css/style.css` — cores e visual (as cores da logo ficam no topo, em `:root`)
- `js/main.js` — cardápio, preços, carrinho e envio do pedido pelo WhatsApp
- `images/` — logo e fotos dos bolos

## Como atualizar
- **Preços e sabores:** edite o objeto `MENU` em `js/main.js`.
- **WhatsApp / Instagram:** edite `WHATSAPP` e `INSTAGRAM` no começo de `js/main.js`.
- **Fotos:** troque os arquivos em `images/` mantendo o mesmo nome.
